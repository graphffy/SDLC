### Дисциплина: Жизненный цикл разработки программного обеспечения

В соответствии с вариантом 8 необходимо разработать утилиту для инвертирования слов. Программа должна получать от пользователя предложение и формировать новое предложение, в котором каждое слово записано в обратном порядке символов. Для выполнения работы поставлены следующие задачи:
1. Создать и настроить проект Java в IntelliJ IDEA и изучить средства редактирования, сборки, запуска и отладки приложения; 
2. Подобрать средства IntelliJ IDEA для работы с UML и SysML v2 и отразить результат настройки в отчёте;
3. Разработать графическое приложение с главной формой и отдельным окном для ввода предложения;
4. Реализовать инвертирование каждого слова введённого предложения с сохранением порядка слов;
5. Обеспечить сохранение последнего корректного предложения и его восстановление при повторном открытии окна ввода;
6. Реализовать проверку входных данных и вывод понятного сообщения при ошибочном вводе;
7. Разделить приложение на модель, представление и контроллер и реализовать активное уведомление представления моделью;
8. Проверить основные сценарии работы программы с использованием средств запуска и отладки IntelliJ IDEA.
